O pipeline, etapa por etapa

Nove etapas, do genoma bruto ao candidato priorizado. Todo o código é Python livre, roda num notebook comum e tem uma demonstração que funciona sem conexão.

cd holinseek

python -m venv .venv

holinseek run data/raw/genomas.fasta

As nove etapas

01

Aquisição dos genomas

Download pelas E-utilities do NCBI, com registro de proveniência: a consulta exata, a lista de acessos e a data ficam gravadas num manifesto JSON ao lado do FASTA, para que a análise possa ser refeita sobre o mesmo conjunto meses depois.

NCBI E-utilities · INPHARED · IMG/VR

02

Controle de qualidade e triagem viral

Descarta contigs curtos demais, sequências duplicadas e material que não é viral. Em metagenomas esta etapa é a que mais economiza tempo adiante.

fastp · CheckV · geNomad

03

Predição de genes

Prodigal em modo viral quando pyrodigal está instalado; caso contrário, um localizador de ORFs de seis quadros embutido no projeto, com o código genético 11. Códons de início alternativos (GTG, TTG) são tratados como metionina inicial — vários cassetes de lise começam justamente neles.

pyrodigal · PHANOTATE

04

Busca por homologia remota

Perfis de domínio contra Pfam e PHROG. Encontra pouco para holinas — esse é justamente o ponto do estudo — mas é o que identifica as endolisinas vizinhas, que são bem conservadas e servem de âncora para a etapa 09.

HMMER / pyhmmer · DIAMOND · Pfam · PHROG

05

Topologia de membrana

Hélices transmembrana por perfil de hidropatia de Kyte-Doolittle, com janela de 19 resíduos e limiar 1,6. É uma heurística: roda offline e serve para a primeira peneira. Para o resultado final, confirme com um preditor treinado.

interno · DeepTMHMM · Phobius · TMbed

06

Atributos físico-químicos

GRAVY, carga líquida em função do pH, ponto isoelétrico, carga da cauda C-terminal, fração transmembrana, aromaticidade. Onze atributos por proteína, todos calculados sem dependência externa.

implementação própria · Biopython ProtParam

07

Estrutura e busca estrutural

Predição de dobramento e comparação por forma, não por alfabeto. Holinas divergem muito em sequência e bem menos em estrutura, então esta etapa recupera parentescos que o alinhamento perde.

ColabFold · AlphaFold DB · Foldseek

08

Aprendizado de máquina

Agrupamento não supervisionado sobre o espaço de atributos, e um classificador supervisionado quando há rótulos auditados. A validação cruzada é agrupada por genoma — sem isso, a acurácia medida é ficção.

scikit-learn · embeddings opcionais

09

Contexto genômico — o cassete de lise

Procura hidrolases de parede celular na vizinhança de cada candidato, dentro de uma janela configurável. É o critério de maior peso de todos: holina e endolisina formam um módulo funcional e viajam juntas.

análise de sintenia · clinker · Pharokka

Os sete critérios

Cada critério é avaliado isoladamente e guardado com o valor medido, o valor esperado e a justificativa. Guardar critério a critério — em vez de só a nota final — é o que torna o resultado auditável.

O código

O filtro físico-químico

Os sete critérios do quadro acima, traduzidos em código. É deliberadamente simples: o valor está em rodar isto sobre todo o espaço de sequências, com proveniência registrada. 

from holinseek.biophysics import compute_features

features = compute_features(sequencia, window=19, threshold=1.6)

candidato = (
    50 <= features.length <= 150
    and 1 <= features.n_tmd <= 4
    and features.gravy > 0.4
    and features.tail_charge >= 3
)

O perfil de hidropatia

A média móvel é calculada de forma incremental — soma o resíduo que entra, subtrai o que sai. Isso mantém o custo linear no comprimento da proteína, o que importa quando se processa milhões de sequências. 

def hydropathy_profile(seq, window=19):
    values = [KYTE_DOOLITTLE.get(aa, 0.0) for aa in seq]
    total = sum(values[:window])
    profile = [total / window]
    for i in range(window, len(values)):
        total += values[i] - values[i - window]
        profile.append(total / window)
    return profile

Orquestração em Nextflow

Para rodar em escala — milhares de genomas, em cluster ou nuvem — o pipeline Python entra como etapa de um fluxo declarativo, com cada passo em contêiner de versão fixada. 

workflow {
  genomas = Channel.fromPath(params.fasta)
  PRODIGAL_GV(genomas)
    | DEEPTMHMM
    | HOLINSEEK_SCORE
    | RANK_CANDIDATES
}

process DEEPTMHMM {
  container 'biocontainers/deeptmhmm:1.0.24'
  cpus 8
  input:  path faa
  output: path 'topology.gff3'
}

A estaca tecnológica

A escolha de cada camada foi guiada por reprodutibilidade, não por desempenho. Um candidato que não pode ser reproduzido não serve para publicar nem para levar à bancada.

O que sai no final

candidatos.tsv

Uma linha por candidato, com os onze atributos, a nota e a faixa de prioridade.

candidatos.json

O mesmo, mais o veredito de cada um dos sete critérios, com valor medido e justificativa.

relatorio.md

Relatório legível: evidências por candidato, ressalvas e o próximo passo experimental sugerido.

Toda saída do pipeline é predição computacional. Nenhum candidato é uma holina até que a bancada demonstre que é.
