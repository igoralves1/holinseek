O que está na apresentação. O problema da resistência antimicrobiana, a biologia do cassete de lise, a química do envelope bacteriano com as fórmulas moleculares, o mecanismo de acionamento, as nove etapas do pipeline com as ferramentas de cada uma, o código, a estaca tecnológica e a validação experimental.

Código

GIT Repositório completo
Pipeline, testes e este site · licença MIT ZIP Baixar como arquivo
Instantâneo do ramo principal 
git clone https://github.com/igoralves1/holinseek.git
cd holinseek
make setup
make demo

O comando make demo roda o pipeline inteiro sobre um genoma sintético que acompanha o repositório, sem baixar nada. É a forma mais rápida de conferir que a instalação funciona.

Dados de exemplo

  • Genoma sintético de demonstração FASTA · 2,5 kb Pseudo-genoma construído para exercitar o pipeline: contém uma proteína com perfil de holina, uma com perfil de endolisina e uma isca neutra. Não corresponde a nenhum organismo real e não serve como resultado biológico.
  • Modelo de arquivo de rótulos CSV Template para treinar o classificador com os seus próprios exemplos auditados. Vem vazio de propósito — a página Camada de IA explica por quê.

Para dados reais, a página Dados e artigos lista as bases públicas, e o comando abaixo baixa um conjunto direto do NCBI: 

holinseek fetch --query fagos-refseq --limit 50
